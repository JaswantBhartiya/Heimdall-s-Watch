How to Run the Test
Upload Firmware: Flash the updated C++ code to your ESP32-S3 via PlatformIO.

Close PlatformIO Serial Monitor: Ensure the serial monitor in VS Code/PlatformIO is closed so the Python script can access the COM port.

Execute Python Script: Run python save_audio.py in your terminal.

Speak into Microphone: Watch the terminal count down 3... 2... 1... [RECORDING_NOW]. Speak or clap near the INMP441 mic for 5 seconds.

Listen to Output: Open esp32_audio.wav directly in Windows Media Player, VLC, or Audacity to verify sound quality.
